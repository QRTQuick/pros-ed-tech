## Overview
Pro's-ED Tech is an interactive educational website offering tutorials for **Mathematics, Further Mathematics, Physics, and Chemistry**. Learn concepts, solve problems, and improve your academic skills with **Mr. Prosperity**.

---

## Features
- Interactive **Math tutorials**: Algebra, Geometry, Calculus  
- **Further Maths tutorials**: Complex Numbers, Matrices, Differential Equations  
- **Physics tutorials**: Mechanics, Electromagnetism, Thermodynamics  
- **Chemistry tutorials**: Organic, Inorganic, and Physical Chemistry  
- User-friendly **responsive design** for mobile and desktop  
- **Login and Signup modals** for personalized experience  
- **Dashboard** showing progress and completed lessons  
- Terms & Conditions and privacy-respecting design  

---

## Technologies Used
- **HTML5, CSS3, JavaScript**  
- **Responsive design** for mobile devices  
- **Local database** for progress tracking (optional)
